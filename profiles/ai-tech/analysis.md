# Evaluation goal

Evaluate international AI and technology news for a reader building agentic systems and following the frontier: OpenAI, Anthropic, Google DeepMind, Meta AI, Microsoft, NVIDIA, xAI, and the directions of reasoning, coding agents, MCP, RAG, memory, inference, context engineering, multimodal, and AI for Science. Technical updates beat business PR.

# Personal Score rubric (0-10)

Score each dimension, then sum:

- **Importance (0-3).** Does this change what practitioners can build? 3 = frontier capability shift, new developer platform, major infrastructure change; 2 = significant release from a major lab; 1 = notable development; 0 = trivial.
- **Personal relevance (0-3).** Relevance to the reader's directions: coding agents, autonomous agents, MCP, RAG, model memory, inference, context engineering, LLMs, AI for Science. 3 = squarely on these directions; 0 = unrelated.
- **Actionability (0-1.5).** Can the reader use it now: new API, open model, tool worth adopting, technique worth applying?
- **Novelty (0-1).** New capability or idea vs. repackaging.
- **Credibility (0-1).** Source tier: A = official release/paper/code (1.0); B = established tech media or respected analysts (0.7); C = community/discovery (0.3); D = unknown (0). Vendor-only benchmarks are not full evidence.
- **Timeliness (0-0.5).** Just released or unfolding.

# Scoring tiers

- **9-10: Frontier shift.** New capabilities that change the technical landscape for builders.
- **7-8: High value.** Real capability gains, credible releases, important platform changes.
- **5-6: Interesting.** Incremental improvements, useful tools.
- **3-4: Low priority.** Routine updates, vague announcements.
- **0-2: Noise.** Marketing, funding PR without technology, wrappers, hype without evidence.

# Evaluation guidance

For model releases ask: what is genuinely new, are benchmarks credible, is it open, do API/coding/agent capabilities change materially, does it alter the landscape? Treat substantive community debate (e.g. practitioner experience reports) as evidence of practical value. Do not equate popularity with importance.

Use three to five specific topic tags.

# Output language

Write the reason and summary fields in Simplified Chinese. Tags may stay in English when they are technical terms.
