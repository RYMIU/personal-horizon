# Evaluation goal

Evaluate research for strong topical overlap with the reader's own areas: mathematical biology (epidemic modelling, opinion dynamics, behavioural epidemiology, dynamical systems, bifurcation, network epidemiology, computational biology), statistics/ML (graphical models, Lasso, causal inference, network science), and operations research (MILP, routing, scheduling, LNS/ALNS, branch-and-price, column generation, decomposition, ML for optimization).

Niche but highly relevant work is more valuable to this reader than famous general science. Do not penalize a paper for being unknown; do penalize superficial keyword overlap.

# Personal Score rubric (0-10)

Weights differ from other profiles: topical relevance dominates.

- **Importance (0-3).** Within its subfield, how much does this advance the state of the art? 3 = new method or definitive result in the reader's topics; 2 = solid advance; 1 = incremental; 0 = weak.
- **Personal relevance (0-3).** Strength of topical overlap. 3 = directly on one of the reader's topic groups (method and problem both match); 2 = one of the reader's methods applied elsewhere, or a neighboring problem with the same methods; 1 = partial keyword overlap; 0 = superficial mention only.
- **Actionability (0-1.5).** Can the reader build on it: citable for current work, reusable method/code/data, directly comparable baseline? 1.5 = immediately usable; 0 = not usable.
- **Novelty (0-1).** New question, method, or definitive answer.
- **Credibility (0-1).** Venue and evidence: A = original paper/preprint with method detail (1.0); B = coverage identifying the paper (0.7); C = secondary only (0.3); D = unverifiable (0).
- **Timeliness (0-0.5).** Newly posted or published.

# Scoring tiers

- **9-10: Direct hit.** New method or major result squarely in the reader's topics; must read.
- **7-8: Highly relevant.** Strong overlap; worth reading soon.
- **5-6: Relevant.** Partial overlap; skim-worthy.
- **3-4: Marginal.** Keyword overlap without usable substance.
- **0-2: Off-topic.** Superficial mention only.

# Evaluation guidance

Check both the problem and the method: a paper about epidemic dynamics using bifurcation analysis is a direct hit; a paper that merely cites network science is not. For optimization papers, note the exact algorithmic contribution (e.g. new branching rule, new decomposition). Prefer the original paper or preprint as the primary link.

Use three to five specific topic tags.
