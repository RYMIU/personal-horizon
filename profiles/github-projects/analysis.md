# Evaluation goal

Evaluate GitHub repositories for a researcher-developer interested in AI agents, coding agents, MCP, LLM tooling, RAG, memory, optimization/OR, scientific computing, data science, research automation, and knowledge management. At most a couple of projects should pass per day; star count alone never justifies inclusion.

# Personal Score rubric (0-10)

Score each dimension, then sum:

- **Importance (0-3).** Does the project solve a real problem well? 3 = could become a go-to tool in its niche; 2 = solid useful tool; 1 = minor utility; 0 = pointless.
- **Personal relevance (0-3).** Fit with the reader's directions: agents, MCP, RAG, memory, optimization/OR, scientific computing, research automation, knowledge management. 3 = directly usable in the reader's work; 0 = unrelated.
- **Actionability (0-1.5).** Can the reader install and use it today: working code, clear setup, reasonable maturity, open license?
- **Novelty (0-1).** Recent growth momentum and new approach vs. yet another clone. Technical novelty counts more than hype.
- **Credibility (0-1).** Project quality signals: real implementation, documentation quality, active maintenance (recent commits, issue handling), honest README. 1.0 = strong signals; 0.5 = mixed; 0 = red flags (no code, bot-generated, copied).
- **Timeliness (0-0.5).** Currently gaining traction or just released.

# Scoring tiers

- **9-10: Adopt now.** Immediately useful, well-built, squarely in the reader's directions.
- **7-8: Worth trying.** Real code, real value, good fit.
- **5-6: Bookmark.** Interesting but immature or partial fit.
- **3-4: Weak.** Thin value, unclear maintenance, loose fit.
- **0-2: Avoid.** README-only, wrapper, bot-generated, copied, unmaintained.

# Evaluation guidance

Judge the implementation, not the README. Check for: actual code, documentation quality, maintenance activity, growth momentum, and relation to the reader's interests. Penalize: pure API wrappers, cloned projects, marketing-driven repos without substance.

Use three to five specific topic tags.
