# GitHub discoveries profile

Use this profile for open-source repositories worth the reader's attention: new or fast-growing projects with real code and practical value in the reader's areas.

Priority directions: AI agents, coding agents, MCP tooling, LLM tooling, RAG, model memory, optimization and operations research tooling, scientific computing, data science, research automation, and productivity/knowledge management.

Typical items include trending repositories with substantive implementations, major releases of useful tools, and new projects solving real problems in the reader's directions.

Do not use this profile for repositories that are only a polished README without working code, thin API wrappers, bot-generated or copied projects, unmaintained projects, awesome-lists without original code, or projects with no relation to the reader's directions. Star count alone is not a signal of value.
